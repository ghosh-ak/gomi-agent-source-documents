# Kitami Gomi AI Source Documents

This repository hosts public reference documents for testing the **Kitami Gomi AI** prototype.

The prototype assists with:

- Waste identification and classification
- Disposal and preparation instructions
- Designated waste bags
- Collection dates for Kitami City

## Notice

This is an experimental research prototype and not an official Kitami City service. Always verify guidance against the original official documents.
