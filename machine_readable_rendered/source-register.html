Kitami Gomi AI Source Register

Source authority, provenance, file mapping, and verification record

Prototype notice: This register documents the sources and derived files used by the research prototype. Original official PDF documents remain unchanged and authoritative.

1. Purpose

This register documents the official source documents used for the Kitami household-waste prototype. It assigns each source a Japanese title, English title, standardized filename, role, priority, and verification status.

2. Source Authority Order

  1. Japanese item dictionary for item-specific classification and disposal instructions.
  2. Japanese household sorting guide for category rules, bag colors, size limits, preparation, and safety requirements.
  3. Official area calendar for collection weekdays and dates.
  4. English sorting guide for resident-facing English explanations.
  5. If an answer remains uncertain, do not guess. Refer the user to Kitami City Waste Management Division.

6. File-Management Rule

  • Keep original PDF content unchanged.
  • Rename only local copies using standardized filenames.
  • Do not edit or overwrite official source PDFs.
  • Keep original filenames recorded for traceability.
  • Store each new municipal edition as a new file and update its validity and edition fields rather than silently replacing the old source.

7. Prototype Provenance Rule

Every answer should ultimately be traceable to an item record in waste_dictionary.json when available, the applicable rule in general_rules.md, the next valid date in collection_schedule.json, and english_guide.md only for clear English phrasing. If required official evidence is missing, the prototype must state that the result is uncertain rather than inventing an instruction.
