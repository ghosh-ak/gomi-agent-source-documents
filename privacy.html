Privacy Statement

Kitami Gomi AI research and prototyping project

Effective date: 22 August 2026

Prototype notice: Kitami Gomi AI is an experimental research prototype. It is not an official service of Kitami City or a replacement for official municipal guidance.

1. Scope

This statement describes the project creator's handling of information associated with the Kitami Gomi AI prototype and its public documentation website. The agent may operate through Microsoft 365 Copilot, which is a separate Microsoft service governed by the applicable Microsoft and organizational privacy terms.

2. Information submitted by users

Users may voluntarily enter questions and may, when the selected platform permits, submit images or descriptions of waste items. Users should not submit names, addresses, faces, identification documents, account credentials, or other sensitive or unnecessary personal information.

3. Information collected by this website

This GitHub Pages website is a static information site. The project creator does not intentionally use forms, cookies, advertising trackers, or custom analytics on these pages. GitHub and a user's browser or network provider may process technical information under their own policies.

4. Purpose of processing

Information supplied to the agent is used to generate prototype guidance about identifying, sorting, preparing, and scheduling household waste disposal using the configured public source documents.

5. Storage and access

The project creator does not operate a separate database for conversations through this static website. Prompts, images, responses, diagnostic information, and account data may nevertheless be processed or retained by Microsoft 365 Copilot, the user's organization, GitHub, or other services involved in access. Users should consult the policies and administrator settings applicable to those services.

6. Public source documents

The agent uses publicly accessible waste-related source documents. Public website content must not be treated as confidential. The project creator aims to identify source materials clearly but does not claim ownership of third-party documents.

7. Accuracy and user responsibility

AI-generated results can be incomplete or incorrect. Users should verify bag type, bag color, preparation requirements, collection area, weekday, and date against the original official documents before acting.

8. Children and sensitive information

The prototype is not designed to collect personal information from children. No user should submit sensitive personal, medical, financial, employment, or confidential institutional information.

9. Changes

This statement may be revised as the prototype, hosting arrangement, or data practices change. The effective date above identifies the current version.

10. Contact

Questions about this prototype can be directed through the contact information published on the creator's website.
